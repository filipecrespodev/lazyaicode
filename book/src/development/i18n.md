# Traduções

Os textos ficam em `crates/i18n/locales/{en,pt,es,zh}.json`, com chaves
`área.chave`. Uma chave que falta num idioma cai no inglês; uma que falta
em todos aparece como a própria chave (visível, nunca um pânico).

```rust
t("thread.land")                                   // "Integrate" / "Integrar"
tf("sidebar.showMore", &[("n", &hidden)])          // "Show 3 more"
```

- `cargo xtask i18n` falha se uma chave usada no código faltar em algum
  idioma.
- `python3 xtask/scripts/i18n_add.py novas.py` acrescenta chaves aos quatro
  arquivos (`T = {"area.chave": ("en", "pt", "es", "zh")}`), sem
  sobrescrever as existentes.
- Chinês, japonês e coreano usam uma fonte CJK do sistema (a embutida não
  cobre); veja [Renderização](../architecture/rendering.md).
